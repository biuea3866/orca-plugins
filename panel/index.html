동작 방식과 첫 사용
  1. 이 패널은 Orca 샌드박스 안에 있어 파일·네트워크에 접근할 수 없습니다. 리뷰 화면은 같은 워크스페이스의 내장 브라우저 탭에 열립니다.
  2. 버튼은 선택한 터미널에 런처 명령 1줄을 입력합니다. 에이전트(claude/codex) TUI가 아닌 셸 터미널을 고르세요.
  3. 첫 사용 전에는 커맨드 팔레트에서 Self Review: 현재 worktree 리뷰 열기 를 1회 실행해 런처를 설치하세요. (단축키 ⌘⌥R)
  4. GitHub에는 어떤 기록도 남기지 않습니다. PR 목록은 gh 읽기 전용 조회입니다.
